# Out of protocol

system-crew는 **참고 → 비슷한 게임 시스템 설계·구현·검증**에 특화됩니다.  
“시스템 크루에게”라고 말해도, 성격이 맞지 않으면 Producer가 루프를 돌리지 않습니다.

| 신호 | 예 | 재라우팅 |
|------|----|----------|
| 에이전트 스킬·룰·팁 문서화 | “이 채팅 습관을 스킬로 남겨줘” | `create-skill` 등 프로젝트 경로 |
| 참고 없는 일상 작업만 | “버튼 색만 바꿔줘” (+ 호출어만) | 일반 구현 (크루 비활성) |
| 툴링·인프라만 | CI, 패키지, 에디터 메뉴 | 해당 프로젝트 워크플로 |
| 메타 문서만 | 에이전트 프롬프트/가이드만 | 스킬·룰 작성 경로 |

## 절차

1. Intake에 `Request type: out_of_scope`
2. 왜 맞지 않는지 한두 문장
3. 올바른 경로 제안 (또는 크루 없이 바로 수행)
4. `docs/references/` 자산·4역할 Stage를 **만들지 않음**

“관찰→분해→자산화 정신만 빌려 달라”고 명시하면, 그 정신은 유지하되 역할 루프·템플릿·INDEX는 생략하고 프로젝트 관례로 수행합니다.
