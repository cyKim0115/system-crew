# Vertical slice

한 번에 게임 전체를 만들지 않습니다. **한 시스템(또는 수직 슬라이스)** 단위로 진행합니다.

## 슬라이스가 의미하는 것

- 플레이어가 체감할 **성공 조건 2~5개**로 범위를 자름
- 데이터/설정과 로직을 분리하고, 플레이 가능한 최소 경로를 먼저
- VFX/SFX 등은 스펙에 있을 때만

## Implementer 검증

컴파일·정적 검사만으로 “완료”를 선언하지 않습니다.

- 에디터 Play / 인게임 경로 / 프로젝트 MCP·자동화로 **런타임** 확인
- 정상 케이스와 엣지 케이스(빈 id, 미보유 슬롯 등)를 함께 봄
- `How to playtest`에 **슬라이스 도달 방법**(타이틀·인트로 대기/스킵 등)을 적음

## 일시 검증 도구

| 종류 | 처리 |
|------|------|
| 이번 검증만 필요한 치트·스킵·디버그 | 검증 후 **폐기** |
| 반복용 플레이테스트 인프라 | 프로젝트 스킬·영구 치트로 유지 |

자세한 출력 형식은 [Implementer](../roles/implementer.md)를 보세요.
